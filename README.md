# Little by Leaf: playtest build

The Brief 01 core-spike playtest of Little by Leaf, for any phone or desktop browser.
Play: https://digitalsri.github.io/little-by-leaf-playtest/

The title offers **Garden A** and **Garden B** (two cores, six gardens each). Settings (the gear) shows the stats line.
The Phase 1 main game is still here: https://digitalsri.github.io/little-by-leaf-playtest/?game=main

This repository holds only the built game files.
